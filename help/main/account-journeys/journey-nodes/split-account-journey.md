# Split and merge paths

Learn how to use split and merge path nodes in Adobe [!DNL Journey Optimizer B2B Edition] to route accounts or people through an account journey according to conditions. This video describes account and people splits, path priority, default paths, and merging.

This tutorial is for marketing professionals and journey designers who use [!DNL Journey Optimizer B2B Edition] to personalize account-based marketing journeys for different segments and buying group members.

>[!VIDEO](https://video.tv.adobe.com/v/3443231/?learn=on&enablevpops)

Learn how to:

* Understand the difference between account paths and people paths. Account paths support account and people steps, nesting, and merging. People paths support only people actions, cannot be nested, and close automatically.
* Add a Split paths node to a journey and choose to split by Accounts or People (up to 25 paths).
* Define path conditions using account attributes, configured custom objects, or matched buying group properties.
* Route accounts by buying group readiness with the _Account has matched buying group_ filter.
* Set path priority. Paths are evaluated top to bottom, and each account follows the first path it matches.
* Use Other accounts or Other people as a default path for unmatched audiences.
* Add actions and events to each account path, then use Merge paths to rejoin them.
* Split by people using person attributes, account-person relationship attributes, buying group membership, custom objects, and event history with lookback windows, frequency, and inactivity filtering.
* Understand how the automatic Close split paths node returns people to the account journey.

For more information, see _[Split and merge paths](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/split-merge-paths-nodes)_ in the user guide.
