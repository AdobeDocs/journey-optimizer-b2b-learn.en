# Listen for Experience Platform events

Use [!DNL Adobe Experience Platform] Experience Events to advance account journeys in [!DNL Adobe Journey Optimizer B2B Edition] when matching activity occurs. Learn how administrators configure event types and fields, and how marketers use them in a [!UICONTROL Listen for an event] node.

>[!VIDEO](https://video.tv.adobe.com/v/3448637/?quality=12&learn=on)

## Experience Event essentials

The video covers these topics:

* Schema and streaming ingestion prerequisites for Experience Events.
* Event types and fields that administrators make available for journey event matching.
* People events, constraints, and filters that marketers use in account journeys.
* Event history filtering for activity that occurred before the listener step.

A listener responds to matching streaming activity when the account reaches that step. Use event history filtering to evaluate earlier activity.
