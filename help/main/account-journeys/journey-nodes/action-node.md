# Take an action node

Use action nodes in [!DNL Adobe Journey Optimizer B2B Edition] to define actions for accounts or people in a journey. Compare account actions and people actions, and learn which actions each journey type supports.

>[!VIDEO](https://video.tv.adobe.com/v/3443207/?quality=12&learn=on)

## Action node essentials

The video covers these topics:

* The purpose of action nodes in a journey.
* The difference between account actions and people actions.
* Action support across journey types.
