# Listen for an event node

Use the [!UICONTROL Listen for an event] node in [!DNL Adobe Journey Optimizer B2B Edition] to advance a journey when an event occurs. Compare account and person events, define matching criteria, and configure timeouts to control how long the journey waits.

>[!VIDEO](https://video.tv.adobe.com/v/3443219/?quality=12&learn=on)

## Listen node essentials

The video covers these topics:

* The difference between account events and person events.
* Matching criteria for event triggers.
* Timeout settings for events that do not occur within the specified time.

## Related documentation

For supported events, configuration steps, and timeout options, refer to [Listen for an event in the user guide](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}.
