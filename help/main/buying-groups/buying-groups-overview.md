# Buying groups overview in Adobe [!DNL Journey Optimizer B2B Edition]

Learn how buying groups organize people for B2B purchase decisions in [!DNL Adobe Journey Optimizer B2B Edition]. This video walks through the components you need, how to prepare a buying group creation job, and how to evaluate readiness.

This tutorial is for marketers and administrators who use [!DNL Journey Optimizer B2B Edition] for account-based marketing and want to target the right stakeholders and qualify accounts.

>[!VIDEO](https://video.tv.adobe.com/v/3433078/?learn=on&enablevpops)

Learn how to:

* Define the four building blocks: roles template, solution interest, account audience, and stages model.
* Open the Buying groups workspace under Accounts and browse the inventory.
* Review a live roles template, including conditions, weighting, priority, and requirements.
* Connect a roles template and an optional stages model to a solution interest.
* Create buying groups by selecting a solution interest and an account audience, then monitor the creation jobs.
* Evaluate buying group completeness, engagement, and intent, and identify missing roles such as Practitioner and Influencer.
* Review and update buying group members. Manual updates take precedence over journey actions and system jobs.
* Use Role insights to compare acquisition and engagement across roles, filtered by date range.

For more information, see _[Buying groups](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-overview)_ in the user guide.
