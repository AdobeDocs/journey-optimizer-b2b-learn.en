# Buying group role templates

Learn how to build role templates in [!DNL Adobe Journey Optimizer B2B Edition]. These templates define who participates in a buying decision, how people are assigned to roles, and what makes a buying group complete. This video covers template creation, role configuration, and publishing.

This tutorial is for marketers and administrators who use [!DNL Journey Optimizer B2B Edition] for account-based marketing and want to target the right stakeholders in each account.

>[!VIDEO](https://video.tv.adobe.com/v/3433079/?learn=on)

Learn how to:

* Open the Roles templates inventory under Buying groups and distinguish draft templates from live ones.
* Create a new role template with a unique name and description.
* Configure a role, including its weighting, automatic assignment, and completeness requirement.
* Define assignment conditions for each role, such as matching on job title.
* To include all participants, add more roles, such as Decision Maker, Practitioner, and Influencer.
* Set role priority so people are assigned to the first role whose conditions they match.
* Use Completeness score settings to set the number of members required for each role.
* Publish a template so its status changes to Live and it is available to solution interests.

For more information, see [Buying group role templates](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates) in the user guide.
